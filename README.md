# Microsoft Agent Framework Course

Course repository for building AI agents with the Microsoft Agent Framework in .NET.

> **Status:** starting point. The solution is set up and projects are added as the course progresses.

## Planned Topics

- Creating an agent and wiring up a chat client
- Tools / function calling
- Conversation state and threads
- Multi-agent orchestration and handoff
- Connecting agents to MCP servers
- Observability and evaluation

## Getting Started

```bash
git clone https://github.com/Fcakiroglu16/microsoft-agent-framework-course.git
cd microsoft-agent-framework-course
dotnet build
```

An API key for your model provider is required; keep it in user secrets or environment variables rather than in source.

## Requirements

- .NET SDK
